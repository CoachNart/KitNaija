# KitNaija visual asset credits

## Third-party 3D assets

- **Universal Base Characters — Quaternius** — CC0 1.0. Runtime source: `https://raw.githubusercontent.com/Seyamalam/blood-league-kickoff/main/public/assets/vendor/quaternius/night-striker.glb`. Used for the player/NPC character layer.
- **car.glb — Babylon.js Assets** — Creative Commons Attribution 4.0 International. Runtime source: `https://raw.githubusercontent.com/BabylonJS/Assets/master/meshes/car.glb`. Used for traffic and drivable vehicles.

The KitNaija gameplay, world dressing, mission systems, UI and procedural fallback geometry are project code. Third-party models are loaded asynchronously with procedural fallbacks so a failed asset request does not prevent the game from starting.
