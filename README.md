# KitNaija

A browser-first Nigerian Web3 onboarding mission game.

## Foundation
- Three.js third-person city movement.
- Mission-first gameplay instead of an empty driving sandbox.
- Lagos chapter with Web3 Hub objective.
- Wallet, transaction, DEX and security lessons as missions.
- 36 states + FCT progression model.
- No wallet required to start.

## Run
npm install
npm run dev

## Direction
Expand state-by-state with authentic Nigerian locations, characters, transport, businesses and dialogue. Web3 concepts are learned by doing.
